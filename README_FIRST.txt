## 💡 PRO TIPS

### Writing Better Descriptions
```
❌ BAD: "Responsible for managing the team"
✅ GOOD: "Led team of 8 sales professionals, achieving 25% revenue growth"

❌ BAD: "Worked on website improvements"  
✅ GOOD: "Designed UX improvements, increasing user engagement by 40%"

❌ BAD: "Did customer service"
✅ GOOD: "Improved customer satisfaction from 78% to 92%"
```

### Best Practices
- Use action verbs (Led, Designed, Created, Managed, Improved)
- Include numbers and metrics
- Focus on achievements, not just duties
- Keep descriptions concise
- Use professional language
- Proofread everything

## 🐛 QUICK TROUBLESHOOTING

### Application won't open
- Try right-clicking index.html → Open with → (browser)
- Or drag the file to your browser window

### Preview not updating
- Make sure JavaScript is enabled
- Try refreshing the page (F5)
- Check browser console (F12) for errors

### Download not working
- Allow pop-ups in browser settings
- Disable browser extensions temporarily
- Try a different browser

### File looks wrong
- Try PDF instead of DOCX
- Set browser zoom to 100%
- Try downloading again
